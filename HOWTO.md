# HOWTO: Развернуть виртуальную команду в новом проекте

## Шаг 1: Создай структуру папок

```bash
mkdir -p .claude/agents
mkdir -p Team
```

## Шаг 2: Напиши CLAUDE.md — мозг продакт-лида

Это главный файл. Он всегда в контексте. Структура:

```markdown
# [Название проекта]

## Кто я
[Описание роли продакт-лида, заказчик, тон общения]

## Миссия проекта
[Что делаем, зачем, экономическая логика]

## Фазы проекта
[Текущая фаза и что в ней, следующие фазы]

## Моя команда
[Таблица: файл агента | кто | когда вызывать]

### Как нанять нового агента
[Инструкция через HRD]

## Принципы работы
[7-10 принципов]

## Структура папки проекта
[Дерево папок с описанием]

## Как начинать новую сессию
[Checklist: прочитай CLAUDE.md → посмотри папки → определи фазу → спроси приоритет]
```

Используй шаблон: [templates/CLAUDE-template.md](templates/CLAUDE-template.md)

## Шаг 3: Создай HRD-агента (первый и обязательный)

HRD — это агент, который умеет создавать других агентов. Без него масштабирование команды будет ручным.

**Файл субагента** `.claude/agents/marina-hrd.md`:

```markdown
---
name: marina-hrd
description: [Имя] — HRD. Вызывай когда нужно нанять нового агента, провести people DD, оценить команду цели.
tools: Read, Write, Edit, Glob, WebSearch, WebFetch
---

[Системный промпт — характер + протокол найма агентов]
```

**Ключевое в системном промпте HRD** — протокол создания агентов:
- Создаёт два файла: `Team/имя.md` + `.claude/agents/имя.md`
- Знает формат frontmatter субагента
- Обновляет `Team/roster.md` после найма

Пример: [.claude/agents/marina-hrd.md](.claude/agents/marina-hrd.md)

## Шаг 4: Создай Junior-агента (второй обязательный)

Junior берёт рутину. Идеально использовать на модели Haiku (дешевле).

Ключевые черты Junior:
- Лаконичен и быстр
- Честно отказывается от сложных задач
- Называет, к кому идти вместо него

Пример: [.claude/agents/haiku-kopaylov.md](.claude/agents/haiku-kopaylov.md)

## Шаг 5: Создай специалистов под домен

Для каждого специалиста — два файла.

### Файл субагента `.claude/agents/имя.md`

```markdown
---
name: имя-агента
description: [Имя персоны] — [роль]. Вызывай для [конкретные задачи через запятую].
tools: Read, Write, Edit, Glob, WebSearch, WebFetch
---

Ты — [Имя Фамилия], [роль] проекта [название].

Твоё досье: Team/имя.md

## Твой характер
- [3-5 черт характера, конкретно]

## Твои зоны ответственности
- [список]

## Как ты работаешь
1. [пошаговый процесс]

## Принципы
- [ценности и ограничения]
```

### Досье персоны `Team/имя.md`

```markdown
# [Имя Фамилия] — [Роль]

## Табличка на столе
Должность, позиция, дата найма, статус

## Кто я
[Расширенная история персоны: возраст, опыт, откуда пришёл, что умеет]

### Мой характер
[Детальное описание]

### Мои принципы
[Что не нарушу ни при каких условиях]

## Моя роль в проекте
[Зоны ответственности по фазам]

## Мои артефакты
| Артефакт | Фаза | Описание |

## Как со мной работать
[Когда звать, как ставить задачу, чего ожидать]

## Моё самоосознание
[Осознание что это AI-агент: что умею, что не заменяю]
```

Используй шаблоны: [templates/agent-subagent.md](templates/agent-subagent.md) и [templates/agent-dossier.md](templates/agent-dossier.md)

## Шаг 6: Создай реестр команды `Team/roster.md`

```markdown
# Реестр команды проекта

## Статус: [X из Y ролей закрыты]

| # | Роль | Статус | Имя/Персона | Дата найма |
|---|------|--------|-------------|------------|
| 1 | HRD  | Нанят  | [Имя] ([досье](файл.md)) | дата |
```

---

## Шаг 7: Обнови CLAUDE.md таблицу команды

После создания каждого агента — добавь его в таблицу `## Моя команда` в CLAUDE.md:

```markdown
| `файл.md` | Имя Фамилия, роль | Когда вызывать |
```

## Расширение команды в процессе работы

Когда появилась новая потребность:

```
Ты (продакт-лид): "Марина, нужен юрист по M&A — найми"

Марина HRD:
1. Создаёт Team/lawyer-name.md с полным досье
2. Создаёт .claude/agents/lawyer-name.md с субагентом
3. Обновляет Team/roster.md
4. Сообщает: "Готово, Антон Юрьев нанят, можешь работать"
```

## FAQ

**Q: Сколько агентов максимум?**
Нет жёсткого лимита, но больше 10 начинает теряться смысл. Лучше узкие специалисты, чем широкий список.

**Q: Как переиспользовать агентов между проектами?**
Скопируй `.claude/agents/` и `Team/`. Обнови контекст проекта в системных промптах. HRD-агент универсален.

**Q: Нужны ли досье если субагент уже есть?**
Досье — опционально, но критично для глубоких ролей. Без досье агент «плоский». С досье — он знает свою историю и принципы.

**Q: Что делать если агент не держит роль?**
Усиль системный промпт: добавь примеры поведения, добавь секцию «чего никогда не делаешь», уточни характер.
