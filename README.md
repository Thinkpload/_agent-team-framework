# Agent Team Framework — Виртуальная команда на Claude Code

Шаблон для воспроизведения концепта «виртуальная команда специалистов» на базе Claude Code Agent SDK.

Каждый член команды — реальный субагент с уникальной личностью, зоной ответственности и системным промптом. Команда управляется продакт-лидом (главным контекстом) и масштабируется через HRD-агента.

---

## Концепт за 60 секунд

```
Продакт-лид (главный CLAUDE.md)
        │
        ├── Marina HRD ──► нанимает новых агентов
        │
        ├── Аналитик рынка
        ├── Финансовый аналитик
        ├── Кастдев-интервьюер
        ├── Dealflow-менеджер
        ├── UX-дизайнер
        └── Junior-ассистент
```

**Продакт-лид** — это ты (главный контекст Claude). Знает всех, координирует, ставит задачи.

**HRD-агент** — умеет создавать новых агентов: пишет два файла (досье + субагент), обновляет реестр.

**Специалисты** — вызываются по контексту через механизм субагентов Claude Code.

**Junior** — дешёвый исполнитель рутины, работает на модели Haiku.

## Структура папок

```
your-project/
├── CLAUDE.md                    # Главный контекст продакт-лида
├── .claude/
│   └── agents/                  # Субагенты Claude Code
│       ├── marina-hrd.md        # HRD-агент (нанимает других)
│       ├── elena-market.md      # Аналитик рынка
│       ├── dmitry-finance.md    # Финансист
│       ├── anastasia-custdev.md # Кастдев
│       ├── ivan-dealflow.md     # Dealflow-менеджер
│       ├── ux-designer.md       # UX-дизайнер
│       └── haiku-kopaylov.md    # Junior (Haiku-модель)
└── Team/
    ├── roster.md                # Реестр нанятых агентов
    ├── hrd-marina.md            # Досье: характер, роль, артефакты
    ├── analyst-market-elena.md
    ├── analyst-fin-dmitry.md
    └── ...
```

## Как воспроизвести для нового проекта

1. **Скопируй структуру** этой папки в новый проект
2. **Адаптируй CLAUDE.md** — опиши миссию, фазы, принципы своего проекта
3. **Адаптируй каждый агент** — измени контекст проекта в системных промптах
4. **Задействуй HRD** для найма дополнительных специалистов по мере роста

Подробная инструкция: [HOWTO.md](HOWTO.md)
